# Referência visual da home estática

Snapshot da home anterior à migração para Angular. Estes arquivos são referência,
não participam do build e não devem receber novas funcionalidades.

A aplicação mantida fica em `frontend/src/`. Veja [as instruções do frontend](../../../README.md).

Para consultar esta referência isoladamente, na raiz do repositório:

```bash
python3 -m http.server 5500 --directory frontend/docs/reference/static-home --bind 127.0.0.1
```

Abra `http://localhost:5500`. O painel apresenta dados fictícios.
